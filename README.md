# 技工物発注・進捗管理アプリ — UIデモ

歯科医院と技工所のあいだの技工物発注・進捗管理アプリの**UIデモ**です。
スマートフォンのブラウザでそのまま操作できます。

👉 **デモ: https://yutaohara023.github.io/bfl-gikou-demo/**

## このデモについて

- **データはすべて架空**です。患者名・カルテ番号はダミー、担当者名は匿名化（Dr A / DH B 等）、
  連絡先・外部ファイルへのリンクもダミーに置き換えています。
- 単一のHTMLファイルで動作します（ビルド不要）。入力内容はブラウザ内にのみ保存されます。

## 試せること

| 画面 | 内容 |
| --- | --- |
| 一覧 | ステータス別の絞り込み、納期超過・予約日超過の警告、検索 |
| 新規発注 | 紙の指示書と同じ歯式チャート（タップ／なぞりで連続選択）、1発注に複数の技工物、納期の自動計算 |
| 案件詳細 | ステータスの前進・巻き戻し・取り消し（履歴は追記のみ）、セット時フィードバック（4段階評価）、患者署名 |
| 帳票 | 技工指示書・保証書の表示と印刷（PDF保存） |
| 納期表 | 発送日から納品日を逆引き（休業日を除いた営業日計算） |

## 操作のヒント

- 「スズキ ケンタ」を開いて **⑥ セット完了** にすると、セット時フィードバックの入力画面が開きます
- 「サトウ ハナコ」の詳細から **技工指示書 / 保証書** を開けます（保証書では署名も試せます）
- ステータスを間違えて進めても「← ひとつ戻す」で戻せます
